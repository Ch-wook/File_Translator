# 0.6.0 실제 화면

API 35 x86_64 에뮬레이터에서 실행한 앱 캡처다. 휴대폰은 1080×2400/420dpi, 태블릿은 2560×1600/240dpi다. 키보드가 열린 입력 상태도 확인했다. 한글 종이/표와 기본 슬라이드는 편집용 재배치이며 원본 조판의 전문 렌더링이 아니다. Word·Excel·PowerPoint는 기본 설정에서 실제 오피스 편집기로 바로 열린다.
