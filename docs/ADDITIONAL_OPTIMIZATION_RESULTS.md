# 문서 스튜디오 추가 최적화 — 0.8.10-preview

기준: 0.8.9 작업 커밋 `0faea43c3395e4e9e26757f621842650a59da0ce`. 미푸시0.8.0 복구본이 아닙니다. 현재 실행 환경은 명령 실행에 실패하여 연결된 GitHub 원격과 Actions를 사용합니다.

이번 후보에서는 모드 전환의 전체 본문 문자열 생성/비교, 불필요한 키보드 요청, 줄 번호 배열의 박싱된 중간 목록, 화면보다 큰 PDF 비트맵을 줄입니다. 읽기 확대는 원본을 고해상도로 다시 렌더하며 페이지/글꼴 데이터는 바꾸지 않습니다. PDF 연속 보기의 페이지·픽셀 스크롤·배율·모드를 보존합니다. 저장되지 않은 PDF의 고해상도 확대에는 기존 미리보기 제한이 남아 있습니다.

읽기 전용 입력/붙여넣기 차단, 같은 문서 View와 선택 영역, 원본 저장/복구, 기존 서명·변환은 유지합니다. 비트맵은 최대 픽셀 예산을 적용하고 화면을 닫을 때 해제합니다. 모든 메모리가 감소했다고 미리 결론 내리지 않습니다.

검증 실행 전 초안입니다. Android54건·단위153건의 실제 실행, 같은 에뮬레이터에서 이전/후보 비교를 진행하며, 성공/실패와 개선되지 않은 값을 실행 후 기록합니다. 비교용 테스트에는 GC 요청 후 메모리·네이티브/Java 힙, PDF3회 열기/닫기, 실제 표시 비트맵 크기, 약50만바이트 TXT 모드 전환을 추가했습니다. GC 요청은 테스트에만 있고 앱의 실제 처리 경로에는 없습니다.

실제 ARM64 휴대폰·삼성/Gboard·S펜, 60fps·배터리·모든 실제 대형 문서의 종합 성능은 이 환경에서 검증할 수 없습니다. 기존0.8.9 배포를 유지하고 별도 `kr.documentstudio.performancepreview` 개발 서명 프리뷰로 제공합니다.
