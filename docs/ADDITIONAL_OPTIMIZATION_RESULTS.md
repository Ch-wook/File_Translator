## 최종 성능 비교

[비교 실행40732103967](https://github.com/Ch-wook/File_Translator/actions/runs/40732103967)에서 기준·후보 각각4개 계측 시험이 통과했습니다. Android35 x86_64 Pixel7 프로필, SwiftShader, RAM3072MiB, 애니메이션 비활성화의 같은 에뮬레이터에서 기준→후보 순서로 실행했습니다. 물리 휴대폰이 아닙니다. 비교용 APK와 배포 APK는 같은 커밋의 앱 코드이며 별도 작업의 서명·해시는 다를 수 있습니다.

시간은 ms·중앙값이며 첫 샘플을 제외하지 않았습니다. 모드·메뉴에는 Compose 클릭/동기화 대기가 포함돼 원시 입력→첫 프레임 지연과 다릅니다.

## 남은 제한

- 실제 ARM64 휴대폰·삼성/Gboard·S펜, 실제 SAF/클라우드 지연·대형 회사 문서·장시간 메모리/배터리·프레임률 미검증.
- 별도 필기 레이어나 문서/양식 수정값을 미리보기로 표시하는 PDF는 기존 비트맵 확대의 선명도 제한이 남습니다. 원본 주석 표시에는 기존 PDFBox 오버레이 분석이 필요할 수 있습니다.
- 연속 보기 offset은 같은 화면 폭/배율의 픽셀 기준입니다. 회전/다른 밀도의 문서 좌표 정규화 복원은 검증하지 않았습니다.
- Word 재배치/제목 탐색, PPT 썸네일 사전 준비·새 스와이프, 큰 XLSX 스트레스 비교, PDF 본문 인라인 선택, 긴 MD preview 재사용, 변환기 전후 속도 비교는 새 완료 범위가 아닙니다.
- OCR·편집 가능한 PDF→DOCX·DOCX↔HWPX·직접 벡터 필기·일괄 변환은 기존과 같이 미지원. 한글 PDF는 페이지 이미지이며 텍스트 검색/선택·링크를 보존하지 않습니다.
