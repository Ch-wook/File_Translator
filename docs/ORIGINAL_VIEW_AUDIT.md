## 확인한 기존 동작

원격 기준의 Office 정책은 문서 로드 뒤 `_switchToEditMode()`를 자동 호출했습니다. 한글 호스트와 엔진 어댑터에도 VIEW/EDIT 권한 제어가 없었습니다. 따라서 원격 기준을 최신 P0 수정본으로 취급할 수 없습니다.

## 재구현 범위

- 문서 열기의 기본값 VIEW와 명시적 EDIT, 형식별 원본 엔진 진입.
- 보기 상태의 입력·변경 명령·undo/redo 차단. 단순히 편집 도구를 숨기는 방식만으로 보호하지 않습니다.
- 같은 문서 인스턴스에서 보기/편집을 전환하며 가능한 실제 엔진 viewport를 보존.
- 원본 대신 앱 전용 작업 복사본을 사용. 승인된 실제 변경만 `.edited` 표시와 작업 수명주기 검사를 거쳐 가져옵니다.
- 읽기만 하거나 수정하지 않은 경우 불필요한 엔진 저장과 원본 재쓰기를 방지.
- 휴대폰에 맞는 접이식·가로 탐색 도구와 형식별 엔진 명령. 지원되지 않는 명령은 사용 가능 상태로 표시하지 않습니다.

## 검증 출처와 제한

로컬 실행 환경은 사용할 수 없었습니다. 실제 실행은 이 브랜치의 GitHub Actions 로그와 산출물에 남깁니다. 테스트가 작성됐다는 사실과 실행·통과는 구분합니다. 현재 실행 결과의 권위 있는 자료는 `verification.zip`의 로그·JUnit·`summary.json`입니다.

실제 Android 휴대폰 종합 검증은 수행하지 않았습니다. GitHub의 Android 에뮬레이터, Robolectric 및 Chromium 터치 화면은 각각 다른 검증이며 실제 휴대폰 결과를 대신하지 않습니다.

상용 프로그램과 동일한 모든 기능이나 문서 코퍼스 전체의 무손실 보존을 보장하지 않습니다. 특히 한글 특수 컨트롤·전용 글꼴, Office 고급 요소·매크로·애니메이션, PDF 임의 글꼴/복잡한 콘텐츠는 추가 검증이 필요합니다.
