# 모바일 공통 편집 UI 개선 (0.8.5-preview)

같은 Android 프로젝트와 Rhwp 0.8.7 / Collabora 엔진을 유지한다. 과거 미푸시 0.8.0 소스를 복구한 것으로 취급하지 않는다.

## 변경

- 한글과 Office가 shared/editor-ui/dist의 동일한 도구·글꼴 목록·패널 컴포넌트를 사용한다. 네이티브 PDF/TXT/Markdown은 MobileEditorControls를 공유한다.
- 편집 상단은 문서명, 뒤로/보기 전환, undo/redo, 저장, 문서 메뉴 한 줄이다. 하단은 기본 도구 한 줄이며 자세한 도구는 기본적으로 닫힌다. 상세 패널은 높이를 제한하고 내부 스크롤·내리기·닫기를 지원한다.
- 상시 안내문과 중복 보기 도구줄을 없앴다. 열기 오류와 저장 오류는 실제 오류 안내로 유지한다. 보호 문서는 읽기 전용 표시와 제한 사유를 제공한다.
- 한글 눈금자는 기본 숨김이며 문서 메뉴에서 복원할 수 있다. 문서 최초 열기는 화면 너비 맞춤, 저장된 위치가 있으면 기존 배율·스크롤을 복원한다. 확대는 문서 글자 크기를 바꾸지 않는다.
- 글꼴 검색·실제 글꼴 미리보기·현재 글꼴·최근 사용을 제공한다. 한글의 맑은 고딕/HY/바탕 등 기존 대체 렌더링 별칭은 원본 표시를 위해 유지하지만 새 선택 목록에서는 실제 번들 글꼴 이름만 제공한다.
- Office에는 기존 앱에 포함된 Noto Sans KR 파일을 실제 엔진 글꼴 디렉터리에도 공급한다. 서식은 네이티브 UNO 명령으로 적용하며 별도 추출 텍스트 편집기를 만들지 않는다.
- TXT/Markdown의 보기 글꼴·크기는 앱 설정이다. 텍스트를 재인코딩하거나 원본 서식으로 저장했다고 표시하지 않는다. Markdown 굵게/목록/표 등은 기존 Markdown 구문 편집으로 유지한다.
- PDF 도구를 같은 하단 패널로 옮기고 페이지·양식·주석·필기·이미지 도구 접근을 유지한다. PDF 확대는 기존 캔버스에서 수행한다.

## 형식별 범위

| 형식 | 공통 UI 및 실제 연결 기능 | 제한 |
|---|---|---|
| HWP/HWPX | 부분 선택 글꼴·크기·굵게/기울임/밑줄/취소선·색상/배경, 자간·장평·위치, 문단·목록·표·그림·검색·스타일 | 엔진이 보존할 수 없는 요소는 기존 저장 검사로 차단. 그림 자르기·교체 등 새 고급 기능을 검증 없이 추가하지 않음 |
| DOC/DOCX | 같은 글꼴 패널·크기·스타일·색상, 문단·표·개체·삽입, 기존 원본 형식 저장 | 자간·장평·문단 세부 설정은 실제 네이티브 대화상자 이용. 기본 글꼴만 복원하는 별도 버튼은 제공하지 않음 |
| XLS/XLSX | 같은 글꼴/크기 도구, 실제 셀·행·열·함수·셀 서식, 시트 UI 유지 | 워드 문단 도구를 셀 문서 구조에 강제 적용하지 않음 |
| PPT/PPTX | 같은 글꼴/크기 도구, 슬라이드·텍스트 상자·개체 배치, 슬라이드 UI 유지 | 개체 편집 범위는 실제 엔진 지원에 따름 |
| PDF | 같은 상단/하단/패널, 원본 페이지·허용 본문/이미지·페이지/양식/주석 도구 | 기존 본문 글꼴 교체·자간/장평·문단 재배치 지원 안 함 |
| TXT | 같은 상단/하단/패널, 입력·선택·클립보드·검색/바꾸기, 보기 글꼴·크기 | 글꼴·색상 등의 원본 서식 없음 |
| Markdown | 같은 상단/하단/패널, 기존 구문 편집·표·목록·제목·링크·미리보기 | 리치 텍스트 글꼴·색상·셀 병합 저장 형식 아님 |
| HTML | 기존 편집기가 없음 | 이번 작업에서 새 형식으로 추가하지 않음 |

## 확인한 결과와 남은 검증

기존 0.8.4 APK에서 추출한 실제 엔진으로 먼저 측정했다. 412×915 화면에서 기본 고정 도구 높이는 216px이고 문서 iframe은 699px이었다. 새 화면은 상단 48px + 하단 48px, 문서 819px이다. 360×800 및 412×500에서도 기본 도구 높이 96px를 확인했다. 마지막 크기는 키보드 높이를 가정한 브라우저 화면이며 Android IME 검증을 대신하지 않는다.

새 코드의 TypeScript, 정책 JavaScript 20건, 실제 브라우저 기본 엔진 5시나리오와 HWP/HWPX 모바일 편집/저장/재열기가 통과했다. 부분 선택·독립 서식·자간/장평의 실제 폭 변화·IME 시뮬레이션·표 병합/분할 3회·그림 이동/크기·undo·독립 파서 검사를 포함한다.

Android 실행 결과와 APK 배포 정보는 최종 검증 뒤 이 문서에 추가한다. 실제 ARM64 휴대폰, 삼성 키보드 및 Gboard 검증은 미완료다. 브라우저 검사나 Robolectric을 실제 휴대폰 검증으로 표시하지 않는다.

## 설치와 배포

기존 0.8.4의 개인 서명키가 없어 별도 프리뷰 applicationId kr.documentstudio.compactpreview를 사용한다. 같은 프로젝트의 개선 빌드이며 기존 앱과 문서를 삭제할 필요가 없다. APK는 두 ABI를 섞은 대용량 파일 대신 arm64-v8a와 x86_64 단일 설치 APK로 각각 검증·배포한다. 아직 올라가지 않은 APK나 이전 Release를 이번 결과로 안내하지 않는다.
