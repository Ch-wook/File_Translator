# 공통 모바일 편집 UI 감사

기준: 원격 `63944c500c5437e478f235598158159a36d99428` / 0.8.4-preview. 기존 미푸시 0.8.0 복구본이라고 표시하지 않는다. 이번 작업은 기존 프로젝트·문서 엔진·파일 저장 구조를 유지한다.

## 확인한 기존 구조

- HWP/HWPX: `web/hangul/index.html`의 header/nav/status, 하단 10개 그룹·상시 quick tools·상세 패널. 실제 글꼴 API와 부분 서식·문단/표/그림·선택 복원 API가 이미 있다. 검색 가능한 글꼴 목록과 간결한 공통 도구 구조를 보완한다.
- DOC/DOCX/XLS/XLSX/PPT/PPTX: `studio-policy.js`의 mode/tabs/actions/hint와 Collabora 자체 메뉴가 함께 표시된다. UNO 명령·실제 읽기 전용·안전 저장·viewport 복원 구조는 유지한다.
- PDF: Compose 상단 앱 바, 편집 상태줄·리본, PDF 자체 도구줄·하단 설명·페이지 바가 겹친다. 지원하는 본문 교체와 이미지 조작·주석 경로를 유지한다. 기존 본문의 임의 글꼴 교체를 가능한 버튼으로 표시하지 않는다.
- TXT/MD: 원본 텍스트용 EditText와 기존 Markdown 명령을 유지한다. 글꼴/크기는 보기 설정이며 원본 파일에 저장되는 서식으로 표시하지 않는다.
- 현재 Format enum에는 HTML이 없다. HTML 편집 지원을 새로 표방하지 않는다.

## 적용 원칙

상단 1줄(뒤로/제목/undo/redo/저장/더보기), 하단 1줄(글자/문단/표 또는 형식별 대상/삽입/더보기), 필요할 때 여는 높이 제한 하단 패널을 기본으로 한다. 작은 아이콘에도 충분한 터치 영역을 확보한다. 안내는 일시 표시하고 오류·저장 상태는 필요할 때 접근 가능하게 유지한다.

공통 DOM 도구·글꼴 패널은 한글/Office에서 같은 자산을 재사용하고 Compose 편집기에는 같은 구성·터치 규칙의 공통 컴포넌트를 적용한다. 형식별 기능은 실제 엔진 능력에 따라 표시한다. 문서 데이터·선택 범위·원본 보호·확대와 글자 크기를 분리한다.

## 검증 계획

기존 APK의 실제 자산·스크린샷과 모바일 viewport 크기를 먼저 기록한다. 변경 후 같은 크기에서 상단·하단 높이와 문서 가시 영역을 비교한다. 실제 HWP/HWPX/Office 부분 서식·저장/독립 파서, Android 키보드·선택·다른 형식·원본 보호를 검사한다. 실행 전 검사를 통과로 표시하지 않는다.
