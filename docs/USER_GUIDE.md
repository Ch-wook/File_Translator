# Android 사용 안내 — 0.8.1-preview

## 열기와 보기

홈의 **파일 열기**, 최근 작업, 다른 앱의 공유/열기로 문서를 선택합니다. 기존 파일은 기본적으로 **원본 보기**로 시작합니다. HWP/HWPX와 Office 문서는 실제 페이지·셀·슬라이드 엔진 화면으로 연결됩니다.

읽기 상태에서는 본문 입력, 한국어 조합, 붙여넣기와 개체 변경을 허용하지 않습니다. 화면 탐색과 확대는 유지합니다. 문서에 없는 글꼴은 대체 글꼴로 표시되므로 원래 프로그램과 줄/페이지 배치가 다를 수 있습니다.

## 문서에서 편집하기

**편집하기**를 누릅니다. 한글/Word는 본문이나 표 셀, Excel은 실제 셀과 수식줄, PowerPoint는 슬라이드의 텍스트 상자·그림·도형을 선택합니다. 선택한 개체의 핸들로 이동/크기를 조정하며, 선택 상태에서 사용할 수 없는 도구는 숨기거나 비활성화합니다. 휴대폰에서는 도구를 접고 가로로 탐색해 문서 공간을 확보하세요.

한글/Office 엔진과 PDF는 같은 문서 화면에서 보기/편집을 전환합니다. TXT/MD도 보기 상태에서는 키보드를 열지 않으며 명시적으로 편집한 뒤 입력합니다. 편집 중 뒤로가기는 우선 보기로 돌아가는 경로를 제공합니다.

## 저장과 다시 열기

엔진은 앱 전용 작업 복사본만 수정합니다. **저장 후 닫기**는 승인된 엔진 결과를 검증한 뒤 원본 반영까지 요청합니다. 일반 작업 화면 복귀는 복구본을 보존하고, 앱의 **저장**으로 원본에 반영할 수 있습니다. 새 문서는 시스템 **다른 이름 저장**에서 위치를 선택합니다.

읽기만 하거나 수정하지 않은 문서를 닫을 때는 엔진 저장과 원본 재쓰기를 하지 않습니다. 외부에서 원본이 바뀌면 충돌을 알리며 다른 이름 저장으로 보존하세요. 보존 검사·내보내기가 실패하면 원본을 반영하지 않고 작업 파일을 남깁니다.

저장 뒤 파일 앱이나 최근 작업에서 다시 열어 수정 내용뿐 아니라 중요한 표·그림·수식·쪽/시트/슬라이드가 유지되는지 확인하세요. 모든 문서의 보존을 자동 인증하는 기능은 아닙니다.

## PDF와 별도 필기

PDF는 원본 페이지로 시작합니다. 명시적 편집 뒤 지원되는 가로 본문과 페이지 직접 이미지를 선택할 수 있습니다. 기존 글꼴이 인코딩하지 못하는 문자, 스캔 이미지 속 글자, 중첩/회전/세로/태그 본문, 재줄바꿈·임의 글꼴 교체는 지원 범위 밖입니다. 기존 내용 삭제는 보안 삭제 기능이 아닙니다. 주석·형광펜·필기는 해당 도구를 선택해서 사용합니다.

**별도 필기**에서는 기존 펜·지우개·올가미·레이어를 사용합니다. PDF 외 필기는 원본과 별도 데이터이며 원본만 옮기면 따라가지 않습니다. 기기 이동이나 앱 설치 변경 전에 **문서·필기 ZIP 백업**으로 보존하세요.

Android 10 이상이며 Office 6형식은 Android 11 이상이 필요합니다. 최신 System WebView를 권장합니다. 실제 휴대폰 종합 검증은 남아 있습니다. [지원 범위](SUPPORT_MATRIX.md)와 Release의 검증 자료를 확인하세요.
