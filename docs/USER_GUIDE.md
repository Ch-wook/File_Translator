# 사용 안내 — 0.5.0

1. APK를 설치하고 새 문서 또는 파일 열기를 누릅니다. 다른 앱의 열기/공유 메뉴도 지원합니다. DOC는 기존 파일만 편집하며 다른 형식은 새 문서를 생성합니다.
2. Word·Excel·PowerPoint는 상단 **정밀 편집**으로 실제 페이지·시트·슬라이드를 엽니다. Android 11 이상에서 지원합니다. 태블릿에서는 리본, 작은 화면에서는 접이식 편집 도구가 표시됩니다. 보기 모드에서는 연필 버튼으로 편집을 시작합니다.
3. 정밀 편집에서 저장 후 닫기 버튼으로 돌아옵니다. 앱 상단 **저장**으로 원본 파일에 반영합니다. 엔진을 닫아 가져온 수정은 앱 Undo의 한 단계이며, 세부 Undo는 엔진 안에서 사용합니다.
4. 기본 Word/한글 화면에서는 각 텍스트 런을 수정하고 글자·문단 서식과 삽입·문서 도구를 사용합니다. DOCX는 표 병합/분할·행열·이미지·머리글/바닥글도 편집합니다. HWPX는 표를 만들고 행열·병합/분할·크기·셀 배경/테두리/세로 정렬을 수정합니다. 표의 텍스트 입력창은 표 번호와 행/열을 표시합니다. 병합한 내용은 시작 셀의 문단으로 유지되고, 분할해도 내용은 시작 셀에 남습니다. 행열/크기 변경 전에는 병합을 해제해야 합니다. 보호·중첩·불규칙 표는 수정하지 않습니다. 한글은 전문 조판이 아닌 구조 편집입니다.
5. 기본 Excel에서 값/=수식을 입력하면 즉시 작업 상태에 반영됩니다. 셀·시트·화면을 바꾸거나 저장하기 전에 별도로 적용할 필요가 없습니다. 주소를 입력하고 체크(셀로 이동) 또는 키보드의 이동을 누르면 해당 셀이 보이도록 표시 창을 옮깁니다. XLS는 A1–IV65536, XLSX는 A1–XFD1048576 범위입니다. XLSX 범위 도구로 복사·붙여넣기·채우기·정렬·행열 변경을 사용합니다. 복잡한 수식/차트/표가 있는 시트의 구조 작업이 거부되면 정밀 편집을 사용합니다.
6. PPTX 기본 미리보기에서 직접 개체를 끌어 이동하거나 위치/크기/회전·순서를 지정합니다. 전체 배치와 테마를 보려면 정밀 편집을 사용합니다.
7. PDF는 축소판·북마크·페이지 도구·검색·텍스트 선택·양식을 지원합니다. **연속 보기**에서 세로로 스크롤하고 확대 슬라이더·가로 탐색을 사용합니다. 각 페이지의 필기 버튼을 누르면 그 페이지의 필기 도구로 이동합니다. 기존 본문 문자열 편집은 목록에서 문자열을 골라 바꿉니다. 원래 폰트가 지원하지 않는 글자나 복잡한 텍스트는 거부합니다. **기존 이미지 편집**에서 직접 이미지를 선택하고 표시 페이지 기준 위치·크기(%)를 지정하거나 삭제합니다. 다른 위치의 같은 이미지 자원은 바뀌지 않습니다. 원래 이미지의 회전·기울기는 지정한 직사각형으로 맞추며 중첩/클리핑/태그/스텐실 이미지는 제외합니다. 보안 지우기나 OCR 기능은 아닙니다.
8. 필기 페이지/PDF 필기로 전환해 펜·색·폭·투명도를 선택합니다. 지우개에서 **지나간 부분만**을 선택하면 해당 구간만 지우고 나머지는 유지합니다. 크기 슬라이더로 지우개 반경을 조절하며 펜을 떼면 적용됩니다. **획 전체** 모드는 닿은 획을 통째로 지웁니다. 두 모드 모두 실행 취소할 수 있습니다. 올가미 선택 후 이동·복사·회전·크기·삭제가 가능합니다. 일반 정전식 펜은 손가락으로 인식될 수 있습니다.
9. 다른 이름 저장·필기 포함 PDF·ZIP 백업·인쇄는 문서 메뉴를 사용합니다. PDF/A 표식이 있는 파일은 일반 PDF로 별도 저장합니다. 정밀 엔진의 PDF 출력은 기본 필기 포함 PDF 출력과 다릅니다.
10. 앱을 다시 열어 최근 작업을 선택하면 복구본을 읽습니다. 정밀 편집 중 강제 종료되면 마지막으로 엔진이 저장한 유효한 파일을 가져옵니다. 실패하면 이전 베이스와 작업 파일을 보존합니다. 문서 메뉴의 **정밀 편집 복구본 보관 후 다시 시작**으로 실패 파일을 보관하고 편집을 재개할 수 있습니다. ZIP의 office-recovery 폴더에도 파일이 포함됩니다.

PDF 외 필기는 원본 파일에 내장되지 않습니다. 기본 XLSX 필기는 셀에 연결되어 기본 도구의 행열 변경/크기/시트 복제에 따라 이동하지만, 정밀 엔진의 구조 변경과 Word/HWP 본문 재조판은 자동 추적하지 않습니다. 원본만 옮기면 필기가 따라가지 않습니다. 기기 이동·앱 삭제·서명 전환 전에 모든 필요한 작업을 ZIP으로 백업하세요. ZIP을 파일 열기로 가져오면 원본 URI에 연결되지 않은 새 작업으로 복원합니다. office-recovery 파일과 provider-backup.bin은 격리된 보존 자료로 가져오며 다음 ZIP 백업에도 포함됩니다. 다른 작업의 pending 표식을 자동 실행하지 않습니다. 새 복구 자료와 이름이 겹치면 이전 자료도 별도 이름으로 보존합니다. 백업은 파일 128 MiB·압축 해제 합계 256 MiB·256파트까지 지원하며 초과 시 대상 파일에 쓰기 전에 안내합니다.

원본이 외부에서 변경되면 덮어쓰기를 거부합니다. 저장 실패 시 원본 복원을 시도하고 실패해도 내부 백업과 복구본을 남깁니다. 앱 데이터를 삭제하지 말고 다른 이름 저장이나 ZIP 백업으로 보존하세요. 기록 직전 입력이나 진행 중 획은 강제 종료 시 유실될 수 있습니다.

열려 있는 문서를 최근 작업이나 파일 열기에서 다시 선택하면 기존 탭으로 돌아갑니다. 탭을 닫기 전까지 실행 취소 이력을 유지하며, 서로 다른 셀·텍스트 런의 입력은 각각 실행 취소할 수 있습니다. 홈으로 돌아가면 입력 키보드를 닫고 최근 작업을 표시합니다. 외부에서 바뀐 파일을 새로 읽으려면 기존 탭을 닫고 다시 여세요. 복구본이 남아 있으면 복구 정책이 우선합니다. Ctrl+Z, Ctrl+Shift+Z/Ctrl+Y, Ctrl+S는 앱의 실행 취소·다시 실행·저장을 사용합니다. 작업 처리 중에는 본문 변경·탭 이동·실행 취소를 잠시 막습니다.

정밀 편집 시작이나 결과 가져오기에 실패한 경우에도 문서 메뉴에 복구 파일 보관 후 다시 시작하는 항목이 표시됩니다. PDF 필기 페이지 표시가 실패하면 화면의 다시 불러오기를 사용할 수 있습니다.

Excel 화면 높이가 부족하면 수식 안내와 25행/열 이동 버튼을 접어 셀 표를 표시합니다. 이때는 주소 입력과 셀로 이동 버튼을 사용하세요. 키보드를 닫거나 창을 넓히면 전체 도구가 다시 표시됩니다.

Excel의 **함수** 버튼에서 이름 또는 한국어 설명(예: 평균)으로 검색하고 사용법·예제를 확인합니다. 빈 셀에서 삽입하거나 `=su`처럼 입력하면 나타나는 `SUM(` 버튼으로 함수 이름을 완성합니다. 기존 셀 참조·완성된 수식·문자열을 지우지 않으며, 인수는 사용자가 입력합니다. 기본 계산기가 지원하는 16개 함수만 목록에 표시합니다.

다른 앱의 열기/공유 요청이 저장·파싱·정밀 편집 중에 들어오면 현재 작업이 끝난 뒤 순서대로 엽니다. 대기 요청은 최대 32개이며 초과 시 다시 선택하라는 안내를 표시합니다.

앱 설정의 오픈소스 라이선스와 정밀 오피스 엔진 고지에서 출처·라이선스를 확인할 수 있습니다.

모든 전문 기능이 검증된 것은 아닙니다. [기능별 확인표](FEATURE_ACCEPTANCE.md)에 기본/정밀 편집의 지원 범위와 미지원·실기기 확인 항목을 구분했습니다.

## 0.4.0 추가 도구

- 탭을 두 개 연 뒤 문서 메뉴의 **두 문서 나란히 편집**을 선택합니다. 넓은 창은 좌우, 세로 공간이 충분하면 위아래로 표시하고 작은 창은 편집 창을 전환합니다. 각 창의 입력·Undo/Redo·저장은 해당 문서에 반영됩니다.
- 홈의 폴더 탐색에서 시스템 선택기로 허용한 폴더를 검색합니다. 하위 폴더의 파일 이름을 찾으며 중지할 수 있습니다.
- PDF 텍스트 선택에서 범위를 지정해 형광/밑줄/취소선을 추가합니다. 주석 관리에서 기존 주석을 고치거나 지웁니다. 가로 보기에서 페이지를 넘깁니다.
- 필기 상세 설정에서 필압 곡선·획 보정·도형 보정을 고르고 펜/색을 즐겨찾기에 저장합니다. 레이어에서 이름/표시/잠금/순서를 관리하고 종이를 바꿉니다. 잠긴 레이어는 지우개/올가미에서도 보호됩니다.
- XLSX 필기에서 시작 셀/확대를 지정합니다. 처음 접촉한 셀에 획을 연결하고 셀로 이동하면 재투영합니다. 문서 도구에서 테두리, 조건부 서식(숫자 비교/중복/해당 범위 지우기), 드롭다운 목록, 데이터 표를 저장합니다. 전체 규칙 표시/입력 강제는 Calc에서 확인하세요.
- Markdown 문법 도구를 사용하고 미리보기 체크박스를 눌러 원문을 바꿉니다. Undo/Redo도 적용합니다.
- HWP의 **HWPX로 변환 → 새 작업으로 변환**을 사용하면 기존 HWP와 별개인 새 탭을 엽니다. **변환 시점 점검 결과**를 확인하고 다른 이름으로 저장하세요. 변환 전 원본/편집본과 보고서는 이 작업의 ZIP/암호 백업에 포함됩니다. 지원하지 않는 제어는 변환을 중단합니다. 글꼴·쪽 배치의 시각적 동일성이나 역변환은 지원하지 않습니다. [상세 제한](HANGUL_CONVERSION.md).
- HWPX 서식에서 자간·장평·위치·문단 간격·기존 스타일·번호/글머리표를 지정합니다. 문서 도구에서 균등 다단과 표 가로 정렬을 바꿉니다. 한컴 전문 조판과 구분합니다.
- OCR에서 이미지 또는 PDF 쪽 범위(최대 20장), 현재 필기를 선택합니다. 한국어+영어/영어 모델은 앱에 포함됩니다. 결과를 검토·수정한 뒤 새 TXT나 검색 가능한 PDF로 적용합니다. 일반 이미지 OCR이므로 손글씨 결과를 검토하세요.
- 문서 메뉴의 **문서·필기 암호화 백업**은 암호를 두 번 입력한 후 .dsbackup으로 저장합니다. 파일 열기에서 같은 암호로 복원합니다. 암호 분실 시 복구할 수 없으며 최대 32 MiB입니다. 기존 ZIP은 그대로 지원합니다. Office/PDF 자체 암호 편집과 다릅니다.
- 설정의 임시 파일 정리는 24시간 지난 지정 중간 파일만 정리하고 문서/복구 자료는 유지합니다.
