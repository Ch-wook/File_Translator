# Android 사용 안내 — 0.7.0-preview

홈에서 새 형식을 선택하거나 **파일 열기**를 사용합니다. 외부 파일 앱의 공유/열기와 최근 작업도 지원합니다. 시스템 파일 선택기에서 권한을 준 파일만 사용하며, 문서를 서버에 업로드하지 않습니다.

HWP/HWPX·Word·Excel·PowerPoint를 열면 각 형식의 실제 엔진 화면으로 진입합니다. 한글과 Word는 본문/표 셀을 눌러 입력하고 상단 메뉴로 서식을 조정합니다. Excel은 셀을 선택하고 셀 입력/수식줄을 사용합니다. PowerPoint는 슬라이드를 선택한 뒤 텍스트 편집 또는 개체 선택 상태로 이동/크기 핸들을 조작합니다. Word 이미지의 자유 배치는 앵커/배치를 조정해야 할 수 있습니다. 엔진이 선택 상태에 따라 사용할 수 없는 도구는 비활성화합니다.

휴대폰에서는 도구를 접거나 가로로 탐색해 문서 공간을 확보합니다. 문서 확대 후 원하는 곳을 누르세요. 태블릿/마우스/키보드도 엔진의 선택과 입력 동작을 사용합니다. 한글에는 Android 이미지 파일 선택기를 연결했습니다. 한글 전용 글꼴이 없으면 번들 대체 글꼴이 표시되므로 줄/페이지가 원래 프로그램과 다를 수 있습니다.

**저장 후 닫기**는 작업 복사본을 저장하고 검증한 뒤 원본 저장까지 요청합니다. 새 문서라면 시스템 **다른 이름 저장**에서 위치를 선택합니다. 원본이 외부에서 바뀌면 덮어쓰기를 거부하므로 다른 이름으로 보존하세요. 한글의 **작업 화면**이나 일반 뒤로가기는 작업 복구본으로 돌아오며 원본은 앱 상단 **저장**으로 반영합니다. 다시 **원본 문서 편집/편집 계속하기**로 들어갈 수 있습니다.

한글의 보존 검사/내보내기가 실패하면 오류가 표시되고 원본은 바뀌지 않습니다. 계속 편집하거나 **저장되지 않은 변경 취소**를 누른 뒤 확인하여 마지막 유효 복구본으로 돌아갈 수 있습니다. 이 동작은 아직 저장되지 않은 최근 입력을 버립니다.

PDF는 처음에 원본 연속 페이지를 보여줍니다. **편집** 탭에서 지원되는 가로 글자를 누르면 그 위치에서 키보드로 입력할 수 있습니다. 페이지의 직접 이미지를 누르고 끌면 이동하며 오른쪽 아래 핸들로 크기를 조절합니다. **적용/취소/이미지 삭제**와 확대 도구를 사용합니다. 글꼴에 없는 문자·중첩/회전/태그 본문·스캔 이미지는 지원하지 않으며 오류 또는 선택 불가로 표시됩니다. PDF 원본은 **저장**을 눌러야 변경됩니다. 본문 교체/이미지 삭제는 보안 삭제 기능이 아닙니다.

**그리기**에서는 기존 펜·형광펜·지우개·올가미·레이어를 사용합니다. PDF 외 필기는 원본과 별도 데이터입니다. 원본만 다른 기기로 옮기면 따라가지 않습니다. 앱 삭제·서명 변경·기기 이동 전에 **문서·필기 ZIP 백업**으로 보존하세요. 필기를 본문 재조판에 자동 부착하는 기능은 제공하지 않습니다.

TXT/MD는 원래 텍스트 형식에 맞는 편집기를 사용합니다. MD는 문법 도구·CommonMark/GFM 미리보기를 제공합니다. 바이너리 오피스 파일을 이 편집기로 대신 열지 않습니다.

Android 10에서는 Word/Excel/PowerPoint 원본 편집을 지원하지 않습니다(Android 11 이상 필요). 한글/PDF/텍스트는 Android 10 이상입니다. 최신 System WebView를 권장합니다. 이 버전은 실기기 인수 전 개발 서명 프리뷰이므로 [지원 범위와 한계](SUPPORT_MATRIX.md)를 확인하세요.
