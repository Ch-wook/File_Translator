# 0.6.0 편집 사용성 전면 개편 실행 계획

사용자 요청: 형식별로 익숙한 문서 프로그램처럼 조작할 수 있도록 편집 UI를 전면 수정한다. 이 문서를 작성한 뒤 아래 순서로 실제 구현·검증·배포한다.

## 문제와 목표

현재는 편집/미리보기/필기/검색이 긴 가로 목록에 섞여 있고, 구조 명령은 하나의 큰 메뉴 안에 숨어 있다. 본문은 런별 테두리 입력칸, 표는 작은 격자 위의 여러 줄 도구, 필기는 다섯 줄 이상의 도구가 차지한다. 기능 수보다 작업의 시작과 선택·입력·저장 흐름을 개선한다.

1. Word/Excel/PowerPoint 파일을 열거나 새로 만들면 실제 페이지/셀/슬라이드 편집기로 바로 연결한다. 기본 편집과 필기 복귀 경로도 유지한다. 원본 대신 검증된 작업 복사본을 편집하는 기존 저장 보호를 사용한다.
2. 형식별 색과 도구 탭을 제공한다. 문서/한글: 홈·삽입·레이아웃·그리기, 표: 홈·삽입·수식·데이터·보기·그리기, 발표: 홈·삽입·슬라이드·그리기, PDF: 보기·주석·편집·페이지·그리기, 텍스트: 홈·보기·그리기.
3. 자주 쓰는 작업을 해당 탭에서 직접 선택한다. 복잡한 작업은 작업 이름으로 찾고, 양식은 선택 목록·스위치·숫자 입력을 사용한다. true/false나 색상 코드를 직접 입력할 필요를 줄인다.
4. 문서/한글은 종이 위의 본문과 선택한 글자 서식, 표는 수식 입력줄·열/행 머리글·하단 시트 탭, 발표는 슬라이드 캔버스·슬라이드 탐색, PDF는 읽기 중심 화면과 필요한 주석 도구를 제공한다.
5. 필기는 펜·형광펜·지우개·선택과 색/굵기를 간결한 기본 줄에 둔다. 종이·레이어·세부 설정은 필요할 때 펼친다. 읽기/손 도구로 문서를 이동할 수 있어야 한다.
6. 홈에서 문서 종류를 고르고 바로 만들 수 있게 하고, 최근 문서는 검색·형식 필터·즐겨찾기로 찾는다. 작은 휴대폰과 태블릿 모두에서 본문 영역을 우선한다.

## 실행 순서와 완료 조건

| 순서 | 작업 | 완료 조건 |
|---|---|---|
| 1 | 공통 디자인·홈·새 문서 | 형식별 아이콘/색, 새 문서 카드, 최근 파일 필터, 저장/복구 상태 표시 |
| 2 | 오피스 직접 편집 진입 | UI 새로 만들기·파일 열기·최근 문서·외부 열기에서 실행, 중복 실행/실패 후 잘못된 문서 열기 방지, 설정에서 변경 가능 |
| 3 | 형식별 리본·명령 | 도구 탭에 실제 작업 연결, 도구 접기, 작업 검색, 기존 삽입·삭제·변환·양식·주석 접근 보존 |
| 4 | 본문·셀·슬라이드·PDF | 테두리 런 폼 제거, 선택 서식, 셀 선택과 수식줄, 시트 탭, 슬라이드 캔버스, PDF 기본 읽기 |
| 5 | 필기 도구 | 기본 작업 줄 축소, 추가 도구/설정 펼치기, 기존 필압·레이어·지우개·필기 보존 |
| 6 | 검증·문서·배포 | 의미 있는 UI/저장 회귀 검사, 휴대폰·태블릿 화면 캡처 확인, 서명 APK/AAB, GitHub 소스와 새 릴리스 |

## 검증 시나리오

- 홈 → 새 형식 선택 → 올바른 작업 화면 → 내용 수정 → Undo/Redo → 회전 → 저장/재열기.
- Word/Excel/PowerPoint 실제 편집 진입 → 편집 결과 복귀와 저장, 설정을 끈 경우 기본 편집 진입.
- 한글 본문 여러 줄 입력/선택 서식, HWP 변환, 표 작업, 슬라이드 선택/이동, PDF 주석·양식·페이지 작업 접근.
- TXT/Markdown 키보드가 떠 있어도 본문 입력과 검색 가능. 선택 탭과 문서 탐색 상태가 회전 후 유지.
- 필기 기본 도구 → 색/굵기 → 지우개/올가미 → 추가 도구/레이어, 기존 필기와 문서 데이터 유지.
- API 35 에뮬레이터 휴대폰(1080×2400/420dpi)과 태블릿(2560×1600/240dpi), 자동 검사와 실제 화면 확인. 실기기 결과로 표시하지 않는다.

## 범위와 기준 자료

익숙한 작업 구조를 적용하며 특정 상용 프로그램의 상표·자산을 복제하지 않는다. UI 개선으로 전문 한글 조판·역변환·PDF/A 인증 등 기존 엔진의 미구현 기능이 지원되는 것으로 표시하지 않는다. 문서의 지원 범위와 제한 설명은 실제 동작과 일치시킨다.

- [Microsoft: 모바일 Word 리본 접기/펼치기](https://support.microsoft.com/en-us/word/show-or-hide-the-ribbon-in-word-for-mobile-devices)
- [Android: 화면에 맞는 레이아웃](https://developer.android.com/design/ui/mobile/guides/layout-and-content/adapt-layout)
- [Android: 기본 적응형 레이아웃](https://developer.android.com/develop/adaptive-apps/guides/canonical-layouts)
