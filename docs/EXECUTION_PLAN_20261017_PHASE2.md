# 0.5.0 후속 실행 계획

기준: 2026-10-17, 원격/로컬 main `ff8f15f`. 0.4.0의 178개 검사와 지원 경계를 유지하며 남은 한글 기능부터 이어서 구현한다.

1. 제작자 공개 HWP→HWPX 변환기(hwp2hwpx, Apache-2.0, edc05278506b663d5bdd98050a51f54b7ff5e0bc)와 hwpxlib 1.0.9를 Android에서 검증한다. 사용 소스·수정·라이선스를 고정한다.
2. 원본과 편집 중인 HWP를 보존하고 새 HWPX 작업으로 변환한다. 입력 구조/작업량을 제한하고 원본과 결과의 구역·문단 텍스트·표/셀·그림 자원·각주 등 실제 구조를 대조한다. 안전하게 처리하지 못하는 제어는 변환 전에 이유와 함께 거부한다. 전문 조판/무손실 인증이나 역방향 변환으로 표시하지 않는다.
3. 변환 결과의 점검 보고서·원본 보존 자료·섹션별 필기/레이어를 새 작업, 재실행, 저장/재열기 및 ZIP/암호 백업에 연결한다. 잘못된 변환/닫힌 대상/외부 선택기 취소가 원본·다른 작업을 바꾸지 않아야 한다.
4. 독립 hwpxlib/DOM과 실제 Android 변환·UI·Undo/저장/재열기·백업/복구 검사를 추가한다. 새 의존성의 Android 호환성/권한/로그와 기존 전체 회귀를 확인한다.
5. 실험과 실제 지원 범위를 문서에 반영하고, 기존 키로 APK/AAB·서명/정렬·소스 패키지를 검증한 뒤 정상 push한다. 수행하지 못한 외부 한컴·조판·역변환 검사는 완료로 집계하지 않는다.

- [x] 변환기 Android 실행/구조 대조 검증. 표/머리말/각주 실제 변환 포함.
- [x] 앱 변환·보고서·보존 자료·필기/백업 연결. Android 통합/UI 5개 통과.
- [ ] 기능/전체 검사·배포 파일·문서·GitHub 반영.
