## 완료 기준

기능마다 화면 조작, 실제 문서 모델 변경, Undo/Redo, 원본 형식 저장, 새 파일로 재열기를 연결한다. 필기 좌표·압력·도구·복구 자료도 검사한다. 버튼/메뉴만 추가하거나 예전 검사 결과를 새 실행으로 집계하지 않는다. 지원 제한을 줄일 때는 기존 보호 장치를 대체하는 검증을 함께 추가한다.

코드로 구현한 기능과 실제 기기·외부 프로그램·표준 적합성 검증을 구분한다. 실제 Galaxy/S펜·외부 Office/한컴·16 KB 기기가 없는 상태에서 해당 검증을 통과로 기록하지 않는다. 전문 조판/문서 호환성/표준 인증을 부분 구현으로 대체했다고 표시하지 않는다.
