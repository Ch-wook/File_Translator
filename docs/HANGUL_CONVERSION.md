# HWP→HWPX 변환 (0.5.0)

HWP의 **HWPX로 변환 → 새 작업으로 변환**을 누른다. 현재 편집 내용을 반영한 HWP를 변환하며 결과를 새 탭으로 연다. 기존 HWP 탭·원본 제공자 파일은 유지된다. 변환 탭에서 **변환 시점 점검 결과**를 열어 점검 범위를 확인하고 다른 이름으로 저장한다. 취소하거나 지원하지 않는 구조를 만나면 변환 탭을 만들지 않는다.

검증 항목은 구역/바탕쪽 수, 문단 텍스트, 표 행열/셀 주소/스팬과 각 셀의 문단, 머리말/꼬리말/각주/미주/캡션/숨은 설명, 개체 수, 첨부 자원의 SHA-256, 그림 참조와 수식 스크립트다. 문단별 텍스트를 구역/개체/셀 범위로 묶어 대조하므로 셀끼리 내용이 바뀌어도 거부한다. 하이픈·탭·줄바꿈·고정/묶음 공백도 비교한다. 서식·색상·용지 등은 upstream 모델이 옮기지만 모든 서식 속성이나 시각적 조판의 일치를 검사하는 것은 아니다.

HWP→HWPX 단방향이며 HWPX→HWP는 제공하지 않는다. 전문 한컴 조판·렌더링·픽셀 동일성·무손실 변환 인증이 아니다. 결과를 외부 한컴 프로그램으로 시각 비교한 검사는 수행하지 않았다. 변환 후 편집은 변환 시점 보고서를 갱신하거나 다시 인증하지 않는다.

변환 탭의 별도 필기는 구역 순서에 연결하고 레이어/잠금/숨김/종이 설정을 유지한다. 본문 재조판을 따라가는 필기는 아니다. 보존 자료는 변환 전 HWP와 현재 편집 HWP, 보고서이며 이 작업의 ZIP 또는 암호 백업에 포함된다. 일반 HWPX 파일만 다른 기기로 옮기면 별도 필기와 보고서는 따라가지 않는다. 백업을 복원하면 보고서·보존 자료와 별도 필기도 복원된다. 보고서는 보존 HWP 해시를 확인한 뒤 표시한다.

지원 제한:

- HWP 5 OLE 파일 16 MiB 이하. 암호/배포/매크로/서명 문서는 기존 감지 정책에 따라 거부한다. 실행 스크립트도 거부하며 기본 빈 스크립트 메타데이터만 허용한다.
- HWP 전체 검사 스트림의 압축 해제 합계 48 MiB, 레코드 깊이 128, 모델 문단 깊이 32, 구역 256, 문단/개체/셀 각각 10,000, 텍스트 500,000 UTF-16 코드 단위, 첨부 자원 256개. HWPX 패키지는 기존 ZIP/XML 제한도 적용한다.
- 표, 그림, 수식, 구역/단 정의, 머리말/꼬리말/각주/미주, 자동/새 번호, 쪽 감추기/쪽 번호, 책갈피, 숨은 설명을 선별 지원한다. 필드/변경 추적/양식, 그림 외 그리기/OLE/차트, 찾아보기 표식, 홀짝 조정, 겹친 글자/덧말, 알 수 없는 제어/인라인 문자는 거부한다.
- 외부 연결 자원과 알 수 없는 내장 자원은 거부한다. PNG/JPG/GIF/TIF/WMF/EMF/SVG 자원을 바이트 단위로 보존·비교한다. 이 형식을 화면에서 모두 렌더한다는 의미는 아니다.
- 한컴 전용 메타데이터/조판 캐시의 완전한 보존을 보증하지 않는다. 보존한 HWP와 변환 결과를 함께 백업한다.
