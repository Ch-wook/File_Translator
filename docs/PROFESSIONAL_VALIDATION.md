# 전문 기능과 남은 인수 조건

2026-10-17. 이번 결과는 실행 가능한 0.4.0 확장판이며 원문의 모든 전문 기능을 완료한 판정은 아니다. [인수 확인표](FEATURE_ACCEPTANCE.md)의 미지원/미검증 행은 완료 수에 넣지 않는다.

| 남은 범위 | 현재 대안/보호 | 필요한 구현·검증 |
|---|---|---|
| 한글 전문 조판·HWP 복합 제어/표·수식/차례·HWP↔HWPX | 일반 문자/검증한 HWPX 구조만 편집, 원본 형식 우선 | Android 오프라인 조판/변환 엔진과 재배포 조건 확정 또는 전체 엔진 개발. 실제 한컴 복합 문서·글꼴·제어·역변환 코퍼스 비교 |
| 정밀 조판/구조 변경 뒤 공통 필기 재배치 | 고정 필기 페이지/기본 XLSX 셀 연결, 구조 변경 전 백업 | 엔진의 안정적 문단/개체 ID·좌표·구조 변경 이벤트와 ink 매핑. 줄 재배치·구역/시트 이름/정렬/삭제 뒤 저장·재열기 |
| PDF/A 판정·편집 후 규격 보증 | 표식 문서 덮어쓰기 거부, 일반 PDF 복사 | veraPDF 등 전체 검증기의 Android 통합·메모리/호환성 및 PDF/A 수준별 코퍼스. XMP 감지는 적합성 검사가 아님 |
| 모든 오피스 고급 메뉴·외부 프로그램 무손실 | 실제 내장 엔진, 기능별 검증 범위 명시 | 현재 검사를 넘는 차트·피벗·마스터·그룹·전환·애니메이션·수식·차례별 저장 및 Microsoft Office 왕복 |
| 실제 S펜·손바닥·저지연·Bluetooth·16 KB·다른 API | 합성 입력/API 35 창, ZIP/ELF 정렬 검사 | Galaxy Tab/S펜과 대상 하드웨어의 이벤트/지연 측정. API 29/36/37·16 KB 장치 실행 |
| 궤적 전용 한국어 손글씨·예측 입력 | 일반 이미지 OCR과 결과 수정, 원시 샘플 유지 | 한국어 궤적 모델/약관·오프라인 성능·취소/예측 오류 복구. 현재 OCR을 전용 모델 성능으로 표시하지 않음 |
| 공개 스토어 출시 | APK/AAB 빌드·서명·권한·정렬 확인 | 기기별 전달 크기와 필요 시 자산 분리, 보안/접근성/전이 라이선스 감사, Play Console 실제 사전 검사. 이번 작업에서 업로드하지 않음 |

이 항목들은 메뉴 추가나 XML 일부 수정으로 충족되지 않는다. 한글 변환을 DOCX 저장으로 대체하거나 PDF/A 표식만 유지해 인증된 파일로 표시하지 않는다.

근거: [Hancom 공개 모델](https://github.com/hancom-io/hwpx-owpml-model)은 형식 구조의 근거이며 페이지 조판/양방향 변환 엔진으로 간주하지 않았다. [veraPDF 배포](https://verapdf.org/software)는 검증 엔진/CLI의 근거이며 이번 APK에는 포함하지 않았다. [Android 16 KB 안내](https://developer.android.com/guide/practices/page-sizes)는 정렬과 실제 장치 실행을 구분한다.
