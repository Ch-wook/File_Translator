# 실패 원인과 재시도 — 2026-10-26

## 개발 환경과 소스 복구

관리 실행 환경이 executor 구성 기능을 조회하는 단계에서 시작하지 못했습니다. 로컬 명령은 실행할 수 없었습니다. 이 제어 계층의 상세 로그와 기존 디스크에 접근할 수 없어 근본 원인, 파일 삭제 또는 손상 여부는 확인하지 못했습니다. GitHub 연결 인증과는 별개의 장애입니다.

GitHub 앱을 통한 원격 파일 읽기와 브랜치 쓰기는 실제로 성공했습니다. 확인 가능한 원격 `2bfe225`를 기준으로 별도 브랜치에서 재구현하고 GitHub Actions에서 빌드·시험합니다. 이전 미푸시 0.8.0 ZIP·패치·커밋·APK의 복구를 주장하지 않습니다. 환경 비공개 식별자나 인증 정보는 저장소에 기록하지 않습니다.

## 통과 판정

CI의 Android 단계는 실패 증거와 APK를 보존하기 위해 continue-on-error를 사용합니다. 따라서 워크플로의 초록색 표시만으로 Android 통과를 선언하지 않습니다. 실제 단계 outcome, JUnit failures/errors, ANDROID_TEST_SUMMARY 및 검증 ZIP의 summary.json을 함께 확인합니다. Release는 실제 Android 단계가 성공한 커밋에만 게시합니다.

실제 휴대폰, 실제 한국어 IME 조합, 모든 문서 형식의 고급 개체·서식 보존은 별도 인수 대상입니다. 실행하지 않은 검사는 통과 수에 포함하지 않습니다.
