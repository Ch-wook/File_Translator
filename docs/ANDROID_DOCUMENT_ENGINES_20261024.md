# Android 원본 문서 편집 개편 — 0.7.0-preview

2026-10-24. 대상은 Android 앱 `kr.documentstudio`입니다. 변경 기준은 “원본 구조로 열기 → 렌더링된 본문/셀/개체를 직접 조작 → 같은 형식으로 저장”이며, 상용 프로그램과 완전히 같은 기능/호환성의 완성을 뜻하지 않습니다.

## 기존 문제와 교체

`DocumentPaper`와 간이 `SheetEditor`는 별도 추출 문단/셀 모델에 연결돼 원본의 조판·개체를 편집하는 경험을 제공하지 못했습니다. 해당 사용자 편집 UI를 제거했습니다. `EditorPolicy`가 지원하는 11개 확장자를 7개 엔진 계열로 명시적으로 분기합니다. 바이너리 문서의 일반 텍스트 편집기 폴백과 설정의 자동 엔진 진입 끄기를 제거했습니다.

- HWP/HWPX: Rhwp 0.8.7의 Rust/WASM 문서 모델·페이지 렌더러·좌표 히트 테스트·편집·직렬화. 실제 페이지 캔버스에서 본문과 셀을 선택하며 단순 `contenteditable` 추출 편집이 아닙니다. 업스트림의 문자/문단·표·이미지/개체·페이지 도구와 Undo/Redo를 사용합니다.
- DOC/DOCX: 별도 `:office` 프로세스의 로컬 Writer. 페이지/표/이미지/도형을 실제 엔진에서 편집합니다.
- XLS/XLSX: 실제 Calc 격자·수식 엔진·시트·차트/개체. 간이 HTML 표로 바꾸지 않습니다.
- PPT/PPTX: 실제 Impress 슬라이드/목록·텍스트 상자·개체 선택/이동/크기 및 슬라이드 명령.
- PDF: PDFBox/Android PDF 렌더러가 만든 원본 페이지 위에 내용 스트림의 문자열·이미지 출현 좌표를 연결합니다. 본문 선택 위치에 Android IME/커서/선택을 제공하고 실제 PDF 글리프를 다시 렌더링합니다. 이미지는 직접 드래그/크기 조절하며 원래 변환행렬의 회전/기울기를 유지합니다. 주석 덮어쓰기로 기존 본문 수정을 대신하지 않습니다.
- TXT/MD: 본래 텍스트/Markdown 문법에 맞는 편집기를 유지합니다.

기존 파서/부분 편집 API는 과거 복구 데이터·변환·저장/테스트에 사용하므로 모두 삭제하지 않았습니다. 사용자 화면에서 바이너리 파일을 그 API의 추출 입력창으로 편집하지 않습니다. 공통 그리기의 읽기용 간이 배경은 별도 필기 기능이며 원본 문서 편집 화면으로 표시하지 않습니다.

## Android 연결과 저장

한글 엔진·폰트·WASM은 APK의 `assets/hangul`에 포함합니다. 고정 출처와 SHA-256 검증을 거쳐 빌드하고 원격 글꼴/PWA/외부 엔진은 끕니다. 전용 HTTPS 자산 원점만 WebView에서 허용합니다. APK에는 INTERNET 권한이 없으며 문서를 서버로 보내지 않습니다. 이미지 삽입은 사용자가 선택한 Android content URI를 사용합니다.

한글 Activity에는 별도 WebView 프로필/프로세스·파일 잠금, 48px 이상 호스트 버튼, 시스템 바/디스플레이 컷아웃/IME 여백 처리를 적용했습니다. 휴대폰은 확대·문서 우선 도구, 태블릿은 엔진 리본을 사용합니다. Word·Excel·PowerPoint도 엔진의 모바일/태블릿 UI와 공통 개체 도구를 사용합니다. 특정 선택에 사용할 수 없는 명령은 비활성화합니다.

엔진에는 원본 SAF URI 대신 검증된 앱 전용 작업 파일만 전달합니다. 한글 저장은 최대 128MiB의 제한된 청크 기록 → 내용 손실 보고 검사 → 같은 형식 확인 → 미해석 누락 ZIP/OLE 파트 보충 → 동기화/원자적 작업 파일 교체 순서입니다. 보고에 손실이 있으면 원본을 변경하지 않습니다. 보고가 모든 원본 정보를 독립적으로 검증한다는 뜻은 아닙니다. 복잡한 컨트롤 내부의 무손실성은 추가 인수가 필요합니다.

호스트로 돌아올 때 불변 베이스와 작업 수정 충돌·파일 잠금을 검사하고 결과를 가져옵니다. 원형식 엔진 출력에 후속 본문 편집이 없으면 **출력 바이트 그대로** 원본에 저장합니다. SAF 저장 전 해시 충돌 확인과 백업, 저장 후 읽기/해시 검사, 실패 시 복원을 유지합니다. 새로운 **저장 후 닫기**는 이 흐름 뒤 원본 반영까지 요청하고, 새 문서라면 시스템 저장 위치 선택기를 엽니다. 일반 돌아가기는 복구본만 유지합니다.

PDF 본문 입력은 exact string ID·기대 원문·새 텍스트 저널로 복구/Undo/저장과 연결했습니다. 편집/읽기/필기 화면 모두 미저장 본문 변경을 렌더링합니다. 이미지 편집은 실제 내용 스트림의 특정 출현만 변경하며 같은 XObject의 다른 출현을 유지합니다.

바이너리 8형식의 간이 텍스트/슬라이드 PDF 출력·인쇄 경로는 차단했습니다. Word·Excel·PowerPoint는 실제 엔진 메뉴로 PDF를 출력합니다. 한글 PDF 출력/인쇄는 이번 통합 범위 밖입니다.

이 결과는 파일 전체 코퍼스나 한컴/MS Office를 자동화한 상용 호환성 인증이 아닙니다. 기존 추출 편집 UI를 대상으로 했던 `WorkspaceRedesignUiTest`는 현재 엔진 전용 호스트와 PDF 캔버스 계약으로 수정했습니다. 오래된 UI 테스트의 과거 통과 수를 현재 결과로 합산하지 않습니다.

**실기기 검증은 미완료입니다.** 현재 환경에는 KVM/연결 기기가 없습니다. API 35 소프트웨어 에뮬레이터가 system_server watchdog 재시작을 반복했고 APK 설치가 PackageManager broken pipe로 실패했습니다. 따라서 connected Android UI·실제 System WebView/한국어 IME 조합·S펜/마우스/키보드·회전/멀티윈도우·네이티브 Writer/Calc/Impress 전체 회귀를 통과했다고 표시하지 않습니다. Robolectric 자산/브리지 검사와 데스크톱 Chromium 터치 에뮬레이션은 이를 대신하는 실기기 증명이 아닙니다.

## 남은 제한과 인수 조건

- 한글: 한컴 전용 글꼴은 번들에 없고 대체 폰트를 사용하므로 원래 줄/페이지와 달라질 수 있습니다. 모든 도형·수식·머리말/꼬리말·배포용/암호 문서·특수 컨트롤의 원형식 무손실을 보장하지 않습니다. 엔진이 보고한 손실은 차단하지만 보고되지 않은 재직렬화 차이는 코퍼스/한컴 재열기로 추가 검증해야 합니다. 모든 표/이미지/페이지 도구의 Android 실기기 검증도 남았습니다.
- Word/Excel/PowerPoint: API 30 이상. 매크로/전자서명 등 기존 보호 정책을 유지합니다. MS 전용 고급 요소·외부 수식·모든 애니메이션/전환/SmartArt/테마의 완전 보존은 보장하지 않습니다. 엔진 기능 연결과 현재 수행한 검증을 구분합니다. 이 작업에서 실제 네이티브 편집/저장 전 과정을 모든 6형식으로 기기 재검증하지 못했습니다.
- PDF: 원폰트가 인코딩할 수 있는 가로 페이지 본문만 수정합니다. 글꼴 대체/재줄바꿈, 중첩 Form/태그/클리핑/회전·세로 본문, 스캔 이미지 속 글자, 보안 삭제는 제외합니다. 원본과 다른 문자를 강제로 덮어쓰지 않고 오류로 알립니다. 완전한 Acrobat SDK가 아닙니다.
- 필기: PDF 외에는 별도 데이터입니다. 엔진의 원본 조판에 공통 필기를 자동 부착하거나 편집 후 앵커를 완전히 추적하지 않습니다. ZIP 백업을 유지해야 합니다.
- 배포: 두 ABI를 포함하는 큰 개발 서명 APK입니다. 실제 사용자 배포 전 출시 키 서명, Android 29/30/35/36·arm64·16KiB·대용량/접근성·상용 프로그램 재열기 검증이 필요합니다. Android 10에서 오피스 6형식은 미지원 안내를 표시하며 추출 텍스트 폴백은 제공하지 않습니다.
