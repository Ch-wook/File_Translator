## 정밀 오피스 편집

상단 **정밀 편집** 또는 문서 메뉴로 진입합니다. Writer/Calc/Impress가 문서 배치를 렌더하고 네이티브 문서 모델을 수정합니다. 엔진의 글꼴·문단·페이지·표·이미지·스타일·시트·수식·차트·슬라이드 도구를 사용합니다. 모바일/태블릿 도구 구성은 다릅니다. 엔진 자체의 기능·포맷 변환 손실과 글꼴 대체 가능성이 있으며 Microsoft Office와의 픽셀 일치나 모든 기능 동등성을 보장하지 않습니다.

공식 26.04.6.0 snapshot build 951과 일치하는 라이브러리 소스를 고정했습니다. 엔진은 별도 :office 프로세스에서 실행하지만 같은 앱 UID이므로 보안 샌드박스를 추가로 제공하는 것은 아닙니다. Java/웹 콘솔 메시지를 버리고 프로세스 로깅 콜백을 차단합니다. AI 서비스는 설정하지 않고 진입 메뉴를 숨깁니다. 인터넷 권한과 분석 SDK는 없습니다.

작업 파일 → 엔진 저장 성공 대기 → 문서 닫기 → 형식 재검사 → 불변 베이스 체크포인트 순서로 가져옵니다. 원래 제공자 파일은 앱의 저장 버튼으로 기록합니다. 엔진 작업 파일은 원본·이전 베이스와 다릅니다. 가져온 결과는 앱 Undo/Redo의 한 단계입니다. 엔진 안에서의 여러 수정은 엔진 자체 Undo/Redo를 사용합니다.

## 기본 Word·한글 도구

DOCX는 글꼴·크기·색·굵게·기울임·밑줄·취소선·강조·위아래 첨자·자간·장평, 문단 정렬·줄/앞뒤 간격·들여쓰기, 문단/쪽 나누기, A4 방향/여백·다단을 저장합니다. 표 행/열 추가·삭제, 직사각형 병합·분할, 배경·테두리·수직 정렬, PNG 이미지, 링크, 기본 머리글/바닥글·쪽 번호를 추가합니다. 복잡하게 병합된 표의 일부 구조 작업은 거부합니다. 기본 화면은 런 편집이며 정밀 보기와 다릅니다.

HWPX는 글꼴·크기·색·굵게·기울임·밑줄·취소선, 문단 정렬/줄 간격·문단/쪽 나누기·A4 여백을 저장합니다. 복잡한 제어 노드가 포함된 텍스트·표 구조·수식·차례·머리말, HWP↔HWPX 변환과 한컴 수준 조판은 미지원입니다. 수정 구역의 줄 배치 캐시를 제거하고 재조판을 요청합니다. 독립 hwpxlib 검사와 실제 한컴 호환성 인증은 다릅니다.

HWP는 제어 코드·범위 태그·보조 평면 문자를 포함한 일부 문자 편집을 거부합니다. OLE 미해석 스트림은 보존하지만 라이브러리가 다시 쓴 레코드 내부까지 완전 무손실이라고 보장하지 않습니다.

## 기본 Excel 도구

XLSX는 셀/수식/글자/배경/정렬/숫자 서식, 시트·병합·행 높이·열 너비·틀 고정·필터 범위를 저장합니다. 실제 Android 클립보드의 TSV 복사/붙여넣기, 상대/절대 수식 범위 복사, 자동 채우기, 값/서식 지우기, 정렬, 행열 삽입/삭제를 제공합니다. 인접한 두 숫자로 같은 시작점의 범위를 채우면 수열을 확장합니다. 최대 10,000셀 작업이며 빈 셀을 뒤로 보내는 안정 정렬입니다. 수식 키 정렬과 일부 병합 범위는 거부합니다.

행열 변경은 같은/다른 시트 수식·범위·이름을 갱신합니다. 안전하게 갱신할 수 없는 공유/배열/데이터 표 수식, 그리기·표·피벗·확장·조건부 서식·데이터 검증·필터를 포함한 시트의 구조 변경은 보수적으로 거부합니다. 3차원/외부/구조화 참조의 완전 갱신은 제공하지 않습니다. 이런 문서는 정밀 편집을 사용합니다.

기본 계산은 사칙연산·거듭제곱·비교·상대/절대 참조·같은/다른 시트 범위와 SUM, AVERAGE, COUNT, COUNTIF, SUMIF, IF, IFS, VLOOKUP, XLOOKUP, INDEX, MATCH, ROUND, MAX, MIN, TEXT, CONCAT입니다. TEXT의 날짜/숫자/백분율과 1904 날짜 체계, 조건 와일드카드를 처리합니다. 순환·깊이·토큰·비교 작업량을 제한합니다. 전체 Excel 계산 의미론·외부 참조·동적 배열·매크로는 기본 계산기의 범위 밖입니다. 지원하지 않는 수식은 원본을 유지합니다.

25×6셀 창과 주소 입력을 제공하며 계산은 Default 디스패처에서 처리합니다. 기본 화면은 전체 병합/행열/차트/조건부 서식을 조판하지 않습니다. 정밀 편집의 Calc 보기와 구분합니다.

## 기본 PowerPoint 도구

PPTX는 런 서식, 텍스트 상자·기본 도형·PNG 이미지 삽입, 위치·크기·회전·개체 순서·삭제, 슬라이드 추가·삭제·복제·순서를 저장합니다. 애니메이션이 참조하는 개체 삭제, 노트/일부 복잡한 관계가 있는 슬라이드 복제는 거부합니다. 기본 미리보기/발표/PDF는 직접 텍스트·그림·일부 도형만 표시합니다. 테마·마스터·그룹·SmartArt·차트·표·전환을 완전히 재현하지 않습니다. 전체 슬라이드 배치는 정밀 편집에서 확인합니다.

## PDF

페이지 추가/삭제/이동/회전/추출/병합, 축소판 탐색, 연속 스크롤 보기와 확대·가로 탐색, 북마크 추가/이름/하위 트리 삭제와 페이지 삭제 시 목적지 보정, 검색·선택·메모·AcroForm 입력을 지원합니다. 본문 텍스트·이미지를 추가합니다. 연속 보기는 현재 필기를 함께 표시하고 페이지별 버튼으로 해당 페이지 필기에 진입합니다. 현재 페이지·북마크·이전/다음 이동이 연속 목록과 연결되며 필요한 페이지만 비트맵으로 렌더합니다. 연속 보기 자체에서는 획을 입력하지 않습니다. 기존 문자열 편집은 페이지 내용 스트림의 가로 Tj/TJ를 실제 수정하며 주석 덮어쓰기가 아닙니다. 기존 폰트로 인코딩 가능한 글자만 허용하고 뒤따르는 문자열 위치를 보정합니다.

세로쓰기·중첩 Form XObject·태그/일부 복잡한 텍스트 상태, 재줄바꿈·폰트 대체, 기존 이미지 이동/삭제, OCR, 보안 지우기는 미지원입니다. PDF 본문 교체는 보안 삭제 기능이 아닙니다. 양식 페이지 삭제/양식 문서 병합은 관계 보호를 위해 거부합니다. PDF/A는 표식 감지 수준이며 veraPDF 검증·PDF/A 저장 인증은 없습니다.

## 필기·공통 기능과 남은 요구사항

펜·만년필·연필·브러시·형광펜·획 지우개·직선/화살표/사각형/원, 색·폭·투명도, 올가미·이동·복사·크기·회전·삭제·숨김·Undo/Redo를 제공합니다. 역사 샘플·필압·기울기·호버·펜 버튼·지우개·스타일러스 우선·손가락 탐색·두 손가락 확대를 처리합니다. 지우개는 획 전체/지나간 부분만 모드와 크기를 선택합니다. 부분 지우기는 실제 획을 열린 구간들로 나누며 남은 필압·기울기·색·폭·투명도를 보존합니다. 빠른 쓸기의 샘플 사이도 검사하고 화면 비율을 반영합니다. 펜을 떼면 적용되며 한 번에 실행 취소합니다. 잘린 도형은 일정 폭의 열린 펜 경로가 됩니다. 지우기는 백그라운드에서 계산하며 과도한 작업량/분할 용량은 원본을 유지하고 거부합니다. 예측 입력·손글씨 OCR/검색·하드웨어 손바닥 분류는 미구현입니다.

PDF 외 필기는 별도 고정 페이지이며 본문/셀 자동 추적이 없습니다. 시트 이름이 유지되면 엔진 파트 변경 시 필기 앵커를 다시 연결하지만 시트 이름 변경·슬라이드 재배열/삭제 후 자동 부착을 보장하지 않습니다. 좌표·구조를 크게 바꾸기 전에 ZIP 백업하세요. PDF 표준 Ink appearance는 일정 폭이고 앱 전용 메타데이터로 필압·기울기·도구를 복원합니다.

탭·최근 검색·즐겨찾기·SAF·공유 열기·시스템 인쇄·원본 백업·충돌 감지·복구 ZIP을 제공합니다. 전체 기기 검색·동시 분할 문서 편집·정밀 조판 위의 공통 필기 통합은 남아 있습니다. 기본 필기 포함 PDF 출력은 오피스 원본 배치와 다를 수 있으며, 정밀 엔진 안의 PDF 출력과 구분합니다.

실제 Galaxy Tab/S펜·하드웨어 입력·API 29/36/37·16 KB 기기·멀티윈도우·접근성 전문 감사·대용량 벤치마크는 미실시입니다. 전체 요구사항 완료로 표시하지 않습니다.
