# 지원 범위 — 0.8.11-preview

현재 기준은 [품질 개선 결과 보고서](COMMERCIAL_QUALITY_RESULTS.md)와 해당 커밋의 Actions·Release 검증 자료다. 아래는 실제 연결한 기능과 제한이다. 모든 문서·기기·고급 요소에 대한 상용 호환성 인증표가 아니다.

기존 파일은 **보기**로 연다. **편집하기**를 선택한 뒤 해당 엔진의 문서·셀·슬라이드·페이지에서 수정한다. 작업 복사본과 원본을 분리하며, 자동 복구본 보존과 원본 저장 완료는 별도로 표시한다. 읽기만 하고 닫으면 불필요하게 저장·재인코딩하지 않는다.

## 서명·필기

PNG 자필 서명 작성, 색상/굵기·undo/redo·지우개, 보관/재사용, 지원 엔진의 그림 위치·크기와 표 셀 삽입을 사용한다. HWPX 안에 삽입한 실제 PNG를 저장하고 엔진으로 다시 연 뒤 PDF에서 파란 서명 획을 확인하는 검사를 제공한다. 인증서 전자서명이나 서명자 신원 확인 기능이 아니다. PDF 외 별도 필기는 복구/백업 자료로 유지하며 본문 재조판 후 자동 부착을 보장하지 않는다. 문서 위 자유 벡터 필기 전체가 완성된 상태는 아니다.

손상 서명 보관함은 빈 목록으로 덮어쓰지 않는다. 저장 복구에서 사본 내보내기와 이전 정상 보관함 복원을 확인 후 선택할 수 있다. 앱 데이터 삭제는 내부 서명·복구 자료도 삭제한다.

## 변환

| 변환 | 처리 | 제한 |
|---|---|---|
| DOCX/DOC·XLSX/XLS·PPTX/PPT→PDF | 기기 내 Collabora의 실제 문서 PDF 필터 | 원본 엔진 레이아웃·폰트 대체·시트 페이지 설정에 따라 차이 가능. 모든 고급 요소 보존 인증 아님. |
| HWPX/HWP→PDF | 기기 내 Rhwp의 전체 페이지 렌더를 PDF 페이지로 생성 | 화면의 보이는 부분 캡처가 아님. 페이지 이미지 방식이므로 텍스트 검색/선택·링크가 유지되지 않음. 배포용 HWP 변환 차단. |
| MD→PDF/HTML/TXT, TXT→PDF/HTML/MD | 기존 PortableConversions, Markdown 해석/텍스트 인코딩, PDF 구조 검사 | MD PDF는 앱의 문법 렌더 지원 범위이며 외부 이미지·복잡한 표/CSS의 완전 보존을 보장하지 않음. TXT→DOCX 미지원. DOCX/HWPX 레이아웃을 텍스트 추출로 대체하지 않음. |
| PDF→PNG/JPG ZIP·TXT | 선택 페이지 렌더, 텍스트 레이어 추출 | 스캔 PDF의 OCR 기반 복원은 이번 변환기에 구현되지 않음. 여러 페이지는 이미지 ZIP. |
| HWP→HWPX | 기존 엔진의 제한된 변환 경로 | 지원 요소와 보존 검사 범위에 한정. 모든 HWP 변환 완료로 표시하지 않음. |
| DOCX↔HWPX·편집 가능한 PDF→DOCX/PPTX/HWPX·일괄/OCR 고급 변환 | 미구현 | 지원 버튼으로 표시하지 않음. |

변환 결과의 실제 형식·이름·출처는 다음 변환 설정과 분리한다. 최신 편집 내용을 기존 엔진에서 처리하며 결과 검증 뒤에만 성공을 표시한다. 내보내기는 원본과 다른 파일을 선택한다. 전자서명·매크로 등의 문서 보호를 우회하지 않는다.

## 실제 글꼴

기존 Noto Sans KR와 엔진 글꼴에 OFL6가족/15개 실제 글꼴 파일을 유지한다. NanumGothic·NanumMyeongjo·Gowun Dodum·Gowun Batang·Lato·Cousine이며, 구성은 config/studio-fonts.json의 고정 출처·커밋·Git blob/크기로 확인한다. 표시 이름만 추가한 맑은 고딕/Arial 등을 포함 폰트처럼 광고하지 않는다. 문서에 해당 글꼴이 없으면 대체 표시와 조판 차이가 생길 수 있다.

## 공통 UI·저장·검증 해석

한 줄 상단과 형식별 하단 도구, 필요할 때 열리는 설정 패널을 재사용한다. 표·그림 도구를 모든 형식에 같은 기능으로 강제하지 않는다. 화면 확대는 원본 서식 변경과 분리한다. 시스템 어두운 색상·큰 글자는 네이티브 도구와 TXT/MD 읽기에 반영하며 엔진의 모든 화면을 접근성 인증한 상태는 아니다.

수정 없는 문서 닫기와 변경된 문서의 저장 확인을 구분한다. 외부 저장 전 원본/최신 사본·해시·단계·프로세스 잠금을 내부 영속 저널에 남긴다. 저장 중 종료·실패 자료를 다음 저장이나 캐시 정리로 지우지 않는다. SAF 전체의 원자적 교체·외부 앱 동시 수정·클라우드 영구 반영을 보장하지 않으며 두 사본이 필요하면 저장 복구에서 새 파일로 꺼낸다.

Android10+ 64비트 앱이며 Office는Android11+다. 실제 x86_64 API35 에뮬레이터·Chromium·독립 파서 검증을 실제 ARM64 휴대폰·S펜·TalkBack 검증으로 표시하지 않는다. 자세한 통과/실패·재열기·성능·보안 범위는 결과 보고서를 확인한다. 현재 프리뷰를 상용 출시 완료로 판정하지 않는다.

인쇄·인쇄 미리보기 기능을 추가하지 않는다. PDF는 별도 파일 변환/저장 결과 형식이다. 기존 Kotlin/Compose·Rhwp·Collabora·PDFBox·CommonMark 구조를 유지한다.
