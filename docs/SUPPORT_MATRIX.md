# 지원 범위 — 0.8.5-preview

공통 모바일 UI·글꼴·부분 선택 서식과 이번 검증은 [0.8.5 결과 보고서](COMMON_MOBILE_UI_RESULTS.md)를 기준으로 확인합니다.

기존 문서는 먼저 보기로 열고 **편집하기** 뒤 해당 엔진에서 수정합니다. 아래는 연결한 기능과 지원 범위이며, 모든 문서에 대한 인수 통과 표가 아닙니다. 실제 실행 결과는 [검증 자료](ORIGINAL_VIEW_RESULTS.md)와 해당 커밋의 Actions를 확인하세요.

| 형식 | 엔진과 도구 | 주요 제한 |
|---|---|---|
| HWP/HWPX | Rhwp 페이지 캔버스, 본문·문단·표/셀·그림·쪽 도구, undo/redo, 같은 형식 내보내기 | 배포용 HWP는 읽기 전용이며 변경 저장·변환을 허용하지 않음. 암호화 HWP 미지원. 전용 글꼴 대체로 조판 차이 가능. 복잡한 도형·수식·특수 컨트롤 전체의 상용 호환성 미인증. 엔진이 보존 불가를 보고하면 저장 차단. |
| DOC/DOCX | Writer 페이지·본문·글자/문단·표·이미지·페이지 도구 | Android 11+. DOC 새 문서 생성 제외. 전자서명·매크로가 있는 Office 패키지는 안전 검사에서 열기가 제한될 수 있음. 고급 MS 요소의 완전 보존 미보장. |
| XLS/XLSX | Calc 실제 셀·수식줄·시트, 행/열·병합·서식·정렬·개체 도구 | Android 11+. 외부 링크·매크로·전용 함수·피벗·동적 배열 전체의 호환성 미보장. |
| PPT/PPTX | Impress 슬라이드 탐색, 텍스트 상자·그림/도형 선택·이동·크기·순서, 슬라이드 명령 | Android 11+. 모든 애니메이션·전환·SmartArt·테마의 완전 보존 미보장. |
| PDF | 원본 페이지, 주석·형광펜·필기, 지원 본문/이미지의 내용 스트림 편집 | 기존 글꼴로 표현 가능한 지원 가로 본문과 직접 이미지에 한정. 임의 글꼴·재줄바꿈·중첩/태그/회전/세로/스캔 본문 편집 제외. 보안 삭제 아님. |
| TXT | 텍스트 보기·직접 입력·검색/교체·인코딩·undo/redo | 원래 텍스트 형식이며 페이지 조판 편집 대상 아님. |
| MD | Markdown 원문 보기/편집과 CommonMark/GFM 미리보기 | 문법 기반 문서. 바이너리 문서를 텍스트 편집기로 대체하지 않음. |

휴대폰은 접이식 도구와 가로 탐색을 사용합니다. 버튼은 실제 엔진 명령과 선택 상태에 연결하며 사용할 수 없는 기능은 제한합니다. 동일한 메뉴가 모든 형식에 같은 기능을 제공한다는 의미가 아닙니다.

원본 대신 작업 복사본을 편집하고 승인된 변경만 검증해 가져옵니다. 원본 저장 시 충돌·백업·복구 정책을 유지합니다. 읽기만 하고 닫으면 불필요한 저장/재인코딩을 하지 않습니다.

이번 모바일 공통 UI 작업은 인쇄·인쇄 미리보기·PDF 출력 도구를 새로 추가하지 않습니다. PDF 외 별도 필기는 앱의 복구/백업 데이터로 유지하며 본문 재조판 후 자동 부착을 보장하지 않습니다. 호스트 분할 화면은 TXT/MD/PDF, 원본 Office 엔진은 한 번에 한 문서씩 실행합니다.

실제 Android 휴대폰에서 형식별 원본 표시·한국어 IME 조합·터치 선택/드래그·저장 후 앱 재실행·모든 고급 요소 보존을 종합 검증하지 못했습니다. 에뮬레이터·Chromium·Robolectric 결과를 실제 휴대폰 결과로 표시하지 않습니다.
