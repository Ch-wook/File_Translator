모든 원본 편집 엔진의 UI를 하나로 강제하지 않습니다. Android 호스트는 파일 수명주기와 별도 필기/복구를 담당합니다. 미지원 Android 버전에서는 엔진 미지원 안내를 표시합니다. 기존 `visualOffice=false` 설정으로 추출 텍스트 편집기로 되돌아갈 수 없습니다.

Word/Excel/PowerPoint의 PDF 내보내기는 엔진의 실제 파일 메뉴를 사용합니다. 호스트의 간이 텍스트/슬라이드 PDF 출력은 이 8개 바이너리 형식에서 차단했습니다. 한글의 PDF 출력/인쇄는 이번 통합에서 제공하지 않습니다. TXT/MD/PDF의 기존 호스트 출력은 유지합니다.

기존 필기는 계속 제공합니다. PDF는 표준 Ink 주석으로 저장하고, 나머지는 별도 복구/백업 데이터로 유지합니다. Word/한글의 재조판·정밀 시트/슬라이드 구조 변경 뒤 필기 자동 부착은 보장하지 않습니다. 두 문서의 호스트 내 동시 편집은 TXT/MD/PDF에 한하며 원본 오피스 엔진은 한 번에 한 문서씩 실행합니다.

[이번 버전의 테스트와 남은 인수 조건](ANDROID_DOCUMENT_ENGINES_20261024.md). 과거 문서의 “기본 Word/Excel/한글 편집”은 이번 버전에서 제거된 UI의 이력입니다.
