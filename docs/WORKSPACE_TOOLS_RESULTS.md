# 문서 스튜디오 0.8.7 작업 도구 보완

기준: 0.8.6 원격 커밋 a7c76a8f… . 이전 미푸시 0.8.0 원본의 복구를 의미하지 않는다.

- PowerPoint: 읽기/편집에서 실제 슬라이드 목록과 이동, 선택 상태 표시, 마지막 슬라이드 삭제 보호와 삭제 확인.
- Excel: 숨겨진 시트를 일반 선택 목록에서 제외, 마지막 표시 시트 삭제 보호, 실제 native dispatcher에 연결한 셀 입력 완료·취소 도구.
- 변경 엔진은 기존 Collabora/LibreOffice이며 새 텍스트 추출 편집기를 만들지 않았다.

검증 진행 중: JavaScript 정책 검사, native 셀 입력 취소/완료와 값 보존, 슬라이드 이동 및 저장 재열기, 기존 전체 39개 Android 회귀. 실행하지 않은 검사를 완료로 계산하지 않는다.

검증한 native API 출처: Actions 40607575083, 0.8.6 APK의 실제 bundle.js 및 cool.html. 실제 ARM64 휴대폰·삼성/Gboard 검증은 미완료이다.

이번 범위에는 슬라이드 순서 변경·썸네일 구현, 고급 차트·PDF 자유 본문 편집을 포함하지 않는다. 이전 저장 및 원본 보호 경로를 유지한다.

실행 결과: native API 검사 40607575083 성공, JavaScript 28건 및 Rhwp 회귀 40611568982 성공, Android 집중 5건 40611569270 성공. 전체 검사와 ABI별 배포 파일 검증은 다음 단계에서 실행한다.
